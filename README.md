# Mike Arena

The cinematic edition of Arena, a Pokémon arena fighter for the iPhone Home Screen.

Play: https://atxr1.github.io/Mike-Arena/ — open it in Safari, then Share → Add to Home Screen.

This branch is the built site served by GitHub Pages. The source, docs and build tools are on the
[`src` branch](https://github.com/atxr1/Mike-Arena/tree/src).
